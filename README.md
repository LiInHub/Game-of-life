\# 康威生命游戏 (Conway's Game of Life)



一个基于 Windows GDI 实现的经典康威生命游戏模拟器，采用 C++ 编写。



\## 项目简介



康威生命游戏是一个零玩家游戏，由英国数学家约翰·霍顿·康威于1970年发明。它属于细胞自动机的一种，通过简单的规则模拟生命的演化过程。



本项目实现了 64×64 的网格，支持鼠标交互和键盘控制，可以实时观察细胞群的演化过程。



\## 功能特性



\-  64×64 网格，可清晰观察大规模演化

\-  标准康威生命游戏规则：

&nbsp; - 存活细胞：2-3个邻居则存活，否则死亡

&nbsp; - 死亡细胞：恰好3个邻居则诞生

\-   鼠标点击切换细胞状态

\-  双缓冲绘图，无闪烁渲染

\-  实时显示存活细胞数量

\-  可切换网格线显示



\## 键盘控制



| 按键 | 功能 |

|------|------|

| `空格` | 开始/暂停游戏 |

| `R` | 随机初始化 |

| `C` | 清空所有细胞 |

| `G` | 切换网格线显示 |
